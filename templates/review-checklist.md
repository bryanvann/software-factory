# Review checklist

Checks this project learned the hard way. The reviewer reads this file on
every PR and applies every item, in addition to the standing review in its
role (correctness, scope, conventions, risk).

Each item is one mechanical check: something the reviewer can do and get a
yes or no. Judgement and principles belong in `AGENTS.md`, not here.

Items arrive through [proposals.md](proposals.md) (tag `[review-checklist]`)
after the operator approves them. Agents do not add to this file directly.
Delete an item once a test or a lint rule enforces it; the checklist is for
what cannot yet be automated.
